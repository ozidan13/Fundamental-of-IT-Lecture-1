What is Information Technology?

ما هي تقنية المعلومات؟

Definition / التعريف

IT is the study and practical use of computer systems, software, and telecommunications to collect, store, protect, process, transmit, and retrieve information.

تقنية المعلومات هي دراسة واستخدام أنظمة الحاسوب والبرمجيات والاتصالات لجمع وتخزين وحماية ومعالجة ونقل واسترجاع المعلومات.

IT Infrastructure Foundations

  • Computing Power (Servers, PCs)
    قوة الحوسبة (الخوادم، الحواسيب الشخصية)
  • Data Storage (Databases, Cloud)
    تخزين البيانات (قواعد البيانات، السحابة)
  • Networking (Routers, Switches)
    الشبكات (أجهزة التوجيه، المحولات)

Key Specialized Areas المجالات المتخصصة

Cybersecurity
الأمن السيبراني: حماية البيانات والأنظمة
Cloud Computing
الحوسبة السحابية: تقديم الموارد عبر الإنترنت
Big Data & Analytics
البيانات الضخمة والتحليلات
Artificial Intelligence (AI)
الذكاء الاصطناعي: أنظمة تحاكي الذكاء البشري

2. What is a Computer?

ما هو الحاسوب؟

Hardware

Physical components you can see and touch.

الأجهزة: المكونات المادية التي يمكنك لمسها ورؤيتها.

Software

Instructions that enable the computer to perform tasks.

البرمجيات: التعليمات التي تمكن الحاسوب من أداء المهام.

4. Hardware Basics أساسيات الأجهزة

Input Devices وحدات الإدخال

Enables user to enter data into computer.

  • Keyboard لوحة المفاتيح
  • Mouse الفأرة
  • Scanner / Barcode ماسح ضوئي
  • Microphone ميكروفون
  • Also: Joystick, Light Pen, OMR, OCR, MICR, Track Ball

Central Processing Unit

CPU - The Brain

وحدة المعالجة المركزية

Machine Cycle

FETCH → DECODE → EXECUTE → STORE

Components

  • ALU (Math/Logic) الحساب والمنطق
  • CU (Control Unit) وحدة التحكم
  • Memory Unit الذاكرة

Output Devices وحدات الإخراج

Shows the result after processing.

  • Monitor الشاشة
  • Printer الطابعة
  • Spkr / Headphone سماعات
  • Plotter الراسخ
  • Projector جهاز عرض

CPU Architecture & Performance

Types of CPU (Cores)

1
Single Core
One task at a time. Early PCs.
2
Dual Core
Two tasks. Entry laptops.
4
Quad Core
Multitasking. Modern PCs.
8+
Hexa / Octa Core
Gaming & Heavy tasks.

Performance (Clock Speed)

GHz / MHz

Rate at which processor completes a cycle.

سرعة الساعة: وتقاس بـ الميجاهيرتز أو الجيجاهيرتز.

CPU Internal Units

  • ALU: Arithmetic (Math) & Logic (Compare).
  • CU: Controls operations, does not process.

5. Memory & Storage الذاكرة والتخزين

RAM (Random Access Memory)

  • Volatile (Temporary).
  • Stores data currently in use.
  • Direct access by CPU.

ذاكرة الوصول العشوائي: مؤقتة، تفقد البيانات عند انقطاع التيار.

ROM (Read Only Memory)

  • Non-Volatile (Permanent).
  • Stores boot-up instructions.
  • Read-only, user cannot change.

ذاكرة القراءة فقط: دائمة، تحتوي على تعليمات بدء التشغيل.

Hard Disk (HDD)
